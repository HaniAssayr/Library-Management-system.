# Library-Management-system.
A simple command-line Library Book Tracker built with Python. This project allows users to manage a collection of books and stores the data in a JSON file so that it is available the next time the program is run.

## Features

* Add a new book
* View all books
* Search for a book by title
* Update book details
* Delete a book
* Borrow a book
* Return a book
* Save and load data using JSON

## Technologies Used

* Python 3
* JSON
* PyCharm

## How to Run

1. Download or clone this repository.
2. Open the project in PyCharm or any Python editor.
3. Run the `library_book_tracker.py` file.
4. Follow the menu displayed in the terminal.
